# FORTAL TECH V1.14.6

## Splash animada
- Logo oficial animada durante a abertura/recarga da página.
- Movimento suave da câmera/logo e varredura dourada.
- Carregamento inicial com animação completa (~1,4 s mínimo).
- Durante o uso, troca de módulos e sincronização usam uma versão rápida (~0,4 s).
- Respeita a preferência de acessibilidade para reduzir movimento.
- Nenhum SQL novo é necessário.
