# FORTAL TECH V1.12.2 — Refinamento visual dourado

Ajustes:
- Notícias & Mercado passa a usar dourado/amarelo como identidade;
- categoria selecionada em dourado;
- fonte da notícia em dourado;
- link "Ler notícia" em dourado;
- indicador ativo do carrossel em dourado;
- filtros, chips, abas e controles selecionados seguem a nova identidade;
- Dashboard recebe acabamento dourado mais uniforme;
- barra inferior mobile reforçada com seleção dourada.

Regra visual:
- dourado/amarelo = identidade, seleção e ação;
- verde = Online, Concluído, Recebido, Pago, Sucesso;
- vermelho = Saída, Cancelado, Erro;
- branco/cinza = conteúdo e navegação neutra.

Não há SQL novo nesta versão.
