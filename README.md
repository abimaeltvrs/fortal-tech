# FORTAL TECH V1.12.1 — Pacote completo de ícones PWA

Nesta versão foram atualizados os ícones usados fora da interface do aplicativo.

Incluído:
- favicon do navegador;
- ícone PWA 192×192;
- ícone PWA 512×512;
- ícone maskable 512×512 para Android;
- Apple Touch Icon 180×180 para iPhone/iPad;
- manifest.webmanifest atualizado;
- cor de tema preta/grafite;
- metadados para instalação no iOS;
- cache/service worker atualizado para a versão V1.12.1.

Arquivos principais:
- public/favicon.ico
- public/favicon-64.png
- public/icon-192.png
- public/icon-512.png
- public/icon-maskable-512.png
- public/apple-touch-icon.png
- public/manifest.webmanifest

Observação:
Celulares que já possuem o app instalado podem manter o ícone antigo por cache do sistema.
Após o novo deploy:
1. abra a versão web uma vez;
2. feche e abra o app;
3. se o Android/iOS ainda mantiver o ícone antigo, remova o atalho/app instalado e instale novamente.

Não há SQL novo nesta versão.
