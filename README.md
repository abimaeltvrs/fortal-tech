# FORTAL TECH V1

Base inicial do sistema de gestão técnica.

## Stack
- React + Vite
- Supabase
- PWA
- Layout responsivo para computador e celular

## Módulos
- Dashboard
- Agenda
- Clientes
- Ordens de Serviço
- Orçamentos
- Financeiro
- Relatórios
- Usuários
- Configurações

## Iniciar localmente
1. Instale Node.js.
2. Execute `npm install`.
3. Copie `.env.example` para `.env`.
4. Preencha URL e chave pública do Supabase.
5. Execute `npm run dev`.

## Banco
O arquivo `supabase/schema_v1.sql` contém a estrutura inicial do banco.
